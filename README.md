# Residencia Dr. Solá - sitio para GitHub Pages

Esta carpeta contiene un sitio estático sin dependencias ni proceso de compilación.

## Publicación

1. Subir `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
2. En GitHub, abrir **Settings > Pages**.
3. Elegir **Deploy from a branch**, seleccionar `main` y la carpeta `/ (root)`.
4. Guardar y esperar a que GitHub muestre la dirección pública.

Los botones de WhatsApp, llamada, ubicación, Instagram y Facebook ya están configurados.
