Criterio del box

Cómo está pensado

No es solo un repositorio. Cada sección intenta transformar materiales dispersos en una ruta de estudio concreta.

Ordenar antes de estudiar

Primero se identifica qué material usar como guía, cuál como consulta y cuál como práctica real de examen.

Priorizar lo que se repite

Los temas frecuentes, ejercicios típicos y finales comentados tienen más peso que la lectura lineal de todo el material.

Fórmulas y ejercicios visibles

Las páginas internas pueden renderizar fórmulas con MathJax para que los ejercicios se vean claros en pantalla.

Escalable

Cada nueva materia puede agregarse como una carpeta independiente, manteniendo el mismo diseño y estructura.
