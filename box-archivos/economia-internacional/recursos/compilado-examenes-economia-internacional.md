# 0. Reglas de trazabilidad y lectura

## 0.1. Tipos de fuente

- **Documento de examen:** archivo cuyo encabezado o contenido identifica la evaluación y su fecha.
- **Captura o aporte estudiantil fechado:** reconstrucción oral o publicación estudiantil con mes/año.
- **CFU o revisión de intento:** evaluación de plataforma, útil para identificar estilo, distractores y mecánica.
- **Banco sin fecha:** pregunta o modelo de ejercicio sin mes/año verificable.
- **Material resuelto:** sirve para estudiar procedimientos, pero no se cuenta como examen adicional.

## 0.2. Reglas de deduplicación

1. Si una pregunta aparece en dos finales con fechas distintas, se conserva en ambas fechas.
2. Si una misma pregunta aparece repetida en compilados sin fecha, se registra una sola vez en el banco temático.
3. Una conversión PDF de un DOCX ya incorporado no se cuenta como fuente nueva.
4. Una resolución manuscrita de un CFU no se cuenta como una evaluación distinta.
5. Las respuestas visibles en revisiones de intento se diferencian de las respuestas entregadas por el estudiante.

## 0.3. Advertencias

- El final reportado como **noviembre de 2025** coincide prácticamente con el PDF fechado **2 de julio de 2025**. Hasta contar con evidencia independiente, se conserva el de julio como fecha confirmada y noviembre como aporte oral posiblemente duplicado.
- En el final de **noviembre de 2021**, la demanda de aspiradoras figura impresa como `D = 55,0000 - 3P`. Se conserva la grafía original y debe verificarse si significa `55.000 - 3P` o `550.000 - 3P` antes de resolver.
- El documento “Mayo 2015. Mismo julio 2014” contiene una afirmación de equivalencia entre llamados. Se registran ambas fechas, aclarando la fuente.

   - ejercicio real;
   - reconstrucción estudiantil;
   - CFU;

   - variante nueva.

7. Usar los CFU para construir distractores de multiple choice.
