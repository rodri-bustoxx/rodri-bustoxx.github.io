# Ruta de estudio — Economía Monetaria

## Si preparás parciales

1. Resolver lo dado en prácticos.
2. Repasar PowerPoint de clase.
3. Usar parciales 2017, 2020 y 2025 como diagnóstico.
4. Volver a bibliografía extensa solo para cerrar una laguna concreta.
